# Gerenciador_de_Tarefas_com_Java

## Sobre o projeto 
Um sistema de controle de tarefas simples utilizando arquitetura em camadas MVC, persistência com CSV, JavaFX para UI e uso da interface Repository para desacoplamento

## Ferramentas utilizadas
  *JavaFX
  *Java 23
  *CSV
  *MVC
  *Repository interface
  *FXML
  *CSS
